# RIKA-А4

Локальное приложение Python + Vue: уведомления, архив SQLite, просмотр и печать А4. Авторизация и интеграция с порталом ещё не подключены. Не открывайте этот сервер в интернет.

## Запуск на Windows

1. Установите Python 3.13+ и Node.js с npm. Встроенный Python не используется.
2. Откройте папку проекта и дважды нажмите `start.cmd`. Первый запуск устанавливает Vue через npm; для него нужен интернет.
3. Откройте **http://127.0.0.1:8000**. Оставьте окно запуска открытым. Остановка — Ctrl+C.

В Microsoft Visual Studio 2026 выберите **Файл → Открыть → Папка** и папку проекта. Для запуска достаточно `start.cmd`; отдельное решение Visual Studio не требуется.

Если порт занят: в PowerShell задайте `$env:RIKA_PORT='8002'`, затем `cmd /c start.cmd`. Адрес станет http://127.0.0.1:8002. Не завершайте неизвестные процессы.

## Настройки и данные

В репозитории только **вымышленные** настройки `backend/settings.example.json` и демонстрационная SVG-шапка. Без локального файла приложение использует этот пример. Для своего филиала скопируйте пример в `backend/settings.json` и замените сведения. Локальные настройки в Git не входят. Идентификатор `astana` оставлен для совместимости; сведения примера вымышленные.

При первом запуске создаётся **пустая** `data/notifications.sqlite3`. Реальных уведомлений и демонстрационной базы в репозитории нет. Не заменяйте существующую базу пустой. Для резервного копирования остановите приложение и сохраните всю папку `data` в защищённое место.

На исходном компьютере сохранены прежние настройки, оригинальная шапка, документы и база. Они исключены из передачи. В клоне оригинального PDF и шапки нет: демонстрационный бланк не является точной копией исходной шапки. Геометрия документа и правила контроля А4 сохранены. Для рабочего бланка требуется отдельная разрешённая передача реквизитов и согласование.

## Работа

Главная предлагает создание или архив. Заполните заказчика, получателя, номер накладной из 13 цифр и дату заказа. Добавьте фактические события, завершив историю вручением, доставкой в ящик, возвратом или уничтожением. Отдельного итога и черновиков нет. Просмотр не создаёт запись; сохранение выдаёт исходящий номер. Печать использует сохранённую версию. Копия из архива не меняет оригинал.

Печатайте А4, книжная ориентация, масштаб 100%, браузерные колонтитулы отключены. Times New Roman должен быть установлен. Основной текст 14 пт, минимум 12 пт требует согласования; переполнение блокирует выдачу. Редкие формулировки и сочетания новых контактов требуют согласования. Источники фраз сохранены в `backend/catalog.json`; исходные клиентские PDF не передаются.

## Проверки

```powershell
npm.cmd ci --no-audit --no-fund
npm.cmd run check
python -m unittest discover -s tests -v
python handoff/audit.py
```

Тестовые сведения в `tests/fixtures.example.json` вымышленные и не загружаются в рабочий архив. Браузерная проверка `node tests/browser.cjs` требует установленного Microsoft Edge и dev-зависимостей npm; пишет отдельные базы и PDF в игнорируемые `artifacts`. Приватные старые инструменты анализа PDF и их результаты не входят в репозиторий.

Перед передачей через GitHub прочитайте `HANDOFF.md`. Приложение не размещено на сервере; фильтрация архива по филиалу не является защитой доступа.
